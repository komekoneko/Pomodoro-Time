# 🕰️ Pomodoro Timer

シンプルなポモドーロタイマーです。作業25分・休憩5分のサイクルで集中力をキープします！

## 📸 機能

- **25分タイマー**：ポモドーロ1セット分の作業時間
- **スタート / ストップ / リセット**：タイマーの基本操作
- **ショートブレイク（5分）**：小休憩モード
- **ロングブレイク（25分）**：長めの休憩モード
- **現在時刻の表示**：リアルタイムで現在時刻を表示
- **効果音**：スタート時・終了時にサウンドを再生

## 🗂 ファイル構成

```
├── index.html      # マークアップ
├── pomodoro.css    # スタイル
├── pomodoro.js     # タイマーロジック
├── start.mp3       # スタート音
└── finish.mp3      # 終了音
```

## 🚀 使い方

1. このリポジトリをクローン or ダウンロード
2. `start.mp3` と `finish.mp3` を同じディレクトリに配置
3. `index.html` をブラウザで開く

> ⚠️ 効果音の再生には `start.mp3` / `finish.mp3` が必要です。ファイルがない場合はコンソールにエラーが出ますが、タイマー自体は動作します。

## ⚙️ 動作仕様

| ボタン | 動作 |
|---|---|
| Start | タイマー開始（二重起動防止あり） |
| Stop | タイマー一時停止 |
| Reset | 25:00 にリセット |
| Break Time (5分) | 残り時間を5:00にセット（青色表示） |
| Break Time (25分) | 残り時間を25:00にセット（青色表示） |

## 🛠 使用技術

- HTML / CSS / JavaScript（バニラJS）
- Web Audio API（`new Audio()`）
- `setInterval` によるカウントダウン制御

## 📝 メモ

- ブラウザのオートプレイポリシーにより、ユーザー操作なしでの音声再生はブロックされる場合があります
- タイマー終了時は `alert()` で通知します
